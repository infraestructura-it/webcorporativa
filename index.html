Comunicación Modbus TCP con Inversores Fronius Symo: Implementación Completa

Implementar comunicación Modbus TCP con inversores Fronius Symo usando registros reales y códigos de función específicos

Configuración de Comunicación:

  • Puerto TCP: 502 (estándar Modbus)
  • Unit ID: 1 (por defecto)
  • Función Code: 0x04 (Read Input Registers)
  • Timeout: 5000ms

Los registros principales del Fronius Symo incluyen:

RegistroParámetroUnidadFactor
40071Potencia AC TotalW1
40092Voltaje AC L1-NV0.01
40097Corriente AC L1A0.01
40251Energía TotalWh1
40263Estado Operacional-1

Implementación Python:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
connection = client.connect()

# Leer potencia AC total
result = client.read_input_registers(40070, 1, unit=1)
potencia_ac = result.registers[0]

# Leer voltaje AC L1-N
result = client.read_input_registers(40091, 1, unit=1)
voltaje_l1 = result.registers[0] * 0.01

print(f'Potencia: {potencia_ac}W, Voltaje L1: {voltaje_l1}V')
client.close()

Protocolo SunSpec Alliance: Estandarización de Inversores Solares

Aprenderá implementación práctica del protocolo SunSpec para interoperabilidad entre inversores de diferentes marcas

El protocolo SunSpec Alliance estandariza la comunicación entre inversores solares, permitiendo interoperabilidad entre marcas como Fronius, SMA, SolarEdge y ABB mediante Modbus TCP/RTU.

La arquitectura SunSpec utiliza bloques de datos normalizados identificados por Model IDs específicos. Cada bloque contiene registros consecutivos con información del dispositivo:

  • Model 1: Información básica (fabricante, modelo, versión)
  • Model 101: Inversor monofásico (potencia, voltaje, corriente)
  • Model 103: Inversor trifásico
  • Model 160: Medidor de energía

La implementación inicia con el SunSpec Header en dirección Modbus 40000, conteniendo la firma 'SunS' (0x53756e53):

import pymodbus
from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
header = client.read_holding_registers(40000, 4)
if header.registers[0:2] == [0x5375, 0x6e53]:
    # SunSpec device detected
    model_id = client.read_holding_registers(40002, 1).registers[0]
    model_length = client.read_holding_registers(40003, 1).registers[0]
    # Read model data
    data = client.read_holding_registers(40004, model_length)

Para inversores trifásicos (Model 103), los registros principales incluyen:

  • 40004-40007: Corrientes por fase (A, B, C)
  • 40014: Potencia AC total (W)
  • 40018: Frecuencia (Hz)
  • 40020: Potencia DC (W)

La ventaja del protocolo SunSpec radica en su autodescubrimiento y mapeo automático de registros, eliminando la necesidad de configuraciones específicas por fabricante. Esto permite desarrollar aplicaciones universales de monitoreo que funcionen con cualquier inversor certificado SunSpec, optimizando la integración en proyectos de gran escala en Colombia.

Comunicación Modbus TCP con Inversores Fronius Symo: Registros y Configuración

Configuración práctica de Modbus TCP en inversores Fronius Symo con registros reales, función codes y código Python

La integración de inversores Fronius Symo mediante Modbus TCP es esencial para sistemas de monitoreo solar en Colombia. Estos inversores implementan el protocolo en puerto 502 con Slave ID 1 por defecto.

Configuración inicial: Activar Modbus TCP en el menú de comunicación del inversor, configurando la IP estática y habilitando el puerto 502. La velocidad de polling recomendada es máximo 1 segundo para evitar sobrecarga del sistema.

Registros principales:

  • 40092: Potencia AC total (W) - Holding Register
  • 40093: Corriente AC L1 (0.01A) - Holding Register
  • 40094: Tensión AC L1 (0.1V) - Holding Register
  • 40096: Frecuencia (0.01Hz) - Holding Register
  • 40100: Potencia DC1 (W) - Holding Register
  • 40103: Tensión DC1 (0.1V) - Holding Register
  • 40113: Energía total (Wh) - Holding Register

Implementación Python:

from pymodbus.client.sync import ModbusTcpClient client = ModbusTcpClient('192.168.1.100', port=502) client.connect() # Leer potencia AC result = client.read_holding_registers(40092, 1, unit=1) if result.isError(): print(f"Error: {result}") else: potencia_ac = result.registers[0] print(f"Potencia AC: {potencia_ac} W") # Leer energía total result = client.read_holding_registers(40113, 2, unit=1) if not result.isError(): energia_wh = (result.registers[1] << 16) | result.registers[0] print(f"Energía total: {energia_wh} Wh") client.close()

Para instalaciones industriales, implementar timeout de 3 segundos y reconexión automática. Los valores se actualizan cada segundo, permitiendo monitoreo en tiempo real para optimización de la producción solar.

from pymodbus.client.sync import ModbusTcpClient

else:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registro 40084)
result = client.read_holding_registers(40084, 1, unit=1)
potencia_ac = result.registers[0] if result.registers[0] < 32768 else result.registers[0] - 65536

voltaje_result = client.read_holding_registers(40088, 1, unit=1)
voltaje_ac = voltaje_result.registers[0] / 100

print(f'Voltaje: {voltaje_ac} V')

client.close()

Registros Modbus principales:

  • 40084-40085: Potencia AC instantánea (Int32, W)
  • 40092-40093: Energía total generada (UInt64, Wh)
  • 40087: Voltaje AC L1-N (UInt16, V)
  • 40090: Corriente AC L1 (Int16, A)
  • 40107: Frecuencia de red (UInt16, Hz/100)
  • 40117: Código de estado operativo

El protocolo utiliza función code 0x03 (Read Holding Registers) para lectura de datos. Los registros están en formato big-endian y requieren conversión según tipo de dato.

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registros 40084-40085)
result = client.read_holding_registers(40083, 2, unit=1)
potencia_raw = (result.registers[0] << 16) | result.registers[1]
potencia_w = struct.unpack('>i', struct.pack('>I', potencia_raw))[0]

# Leer voltaje AC L1
voltaje = client.read_holding_registers(40086, 1, unit=1)
voltaje_v = voltaje.registers[0] / 100

client.close()

Implementación práctica de Modbus RTU con inversores SMA Sunny Boy en Colombia

Configuración técnica detallada de comunicación Modbus RTU con registros reales y código Python para monitoreo

Los inversores SMA Sunny Boy utilizan protocolo Modbus RTU para comunicación industrial, esencial en proyectos solares colombianos que requieren monitoreo centralizado.

Configuración Hardware:

  • Baudrate: 9600 bps
  • Data bits: 8, Stop bits: 1, Paridad: None
  • Dirección esclavo por defecto: 3
  • Terminación 120Ω en extremos del bus RS485

Registros Modbus críticos:

  • 30775-30776: Potencia AC instantánea (W) - 32-bit unsigned
  • 30513-30514: Tensión DC entrada 1 (mV) - 32-bit unsigned
  • 30517-30518: Corriente DC entrada 1 (mA) - 32-bit unsigned
  • 30805-30806: Energía total generada (Wh) - 32-bit unsigned
  • 30825: Temperatura del inversor (°C) - 16-bit signed
  • 30201: Estado operacional - 16-bit unsigned

Implementación Python:

from pymodbus.client.sync import ModbusSerialClient

client = ModbusSerialClient(method='rtu', port='/dev/ttyUSB0',
baudrate=9600, timeout=3)
client.connect()

# Leer potencia AC (registros 30775-30776)
result = client.read_holding_registers(30775, 2, unit=3)
if not result.isError():
power_ac = (result.registers[0] << 16) + result.registers[1]
print(f"Potencia AC: {power_ac} W")

# Leer temperatura
temp_result = client.read_holding_registers(30825, 1, unit=3)
temp_celsius = temp_result.registers[0] / 100
print(f"Temperatura: {temp_celsius}°C")

client.close()

Consideraciones técnicas: Los registros 32-bit requieren lectura de dos registros consecutivos. El estado operacional (30201) indica: 35=MPP, 381=Apagado, 455=Advertencia. Para instalaciones en altitudes colombianas >2000m, monitorear temperatura constantemente.

Esta implementación permite integración con SCADA locales y cumple normativas CREG para reporte de generación distribuida.

  • 40070-40071: Potencia AC instantánea (Uint32, W)
  • 40092-40093: Energía total generada (Uint32, Wh)
  • 40101: Voltaje DC String 1 (Uint16, V)
  • 40103: Corriente DC String 1 (Uint16, A)
  • 40108: Temperatura del inversor (Int16, °C)
  • 40118: Estado de operación (Uint16)

El protocolo utiliza función code 04 (Read Input Registers) para lecturas. Los valores requieren factores de escala según especificaciones SunSpec.

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)

# Leer potencia AC (registros 40070-40071)
result = client.read_input_registers(40069, 2, unit=1)
if result.isError():
print('Error en lectura')
else:
power_raw = (result.registers[0] << 16) + result.registers[1]
power_watts = power_raw if power_raw < 2**31 else power_raw - 2**32
print(f'Potencia AC: {power_watts} W')

temperature = temp_result.registers[0]
print(f'Temperatura: {temperature/10} °C')

client.close()

Protocolo Modbus TCP/RTU con Inversores Fronius Symo: Guía Implementación

Configuración práctica de registros Modbus para monitoreo de inversores Fronius Symo con códigos Python funcionales

Los inversores Fronius Symo implementan protocolo Modbus TCP (puerto 502) y RTU (RS485) siguiendo estándar SunSpec, facilitando integración en sistemas SCADA colombianos.

Configuración de Registros Principales:

  • 40084-40085: Potencia AC Instantánea (32-bit Float, Factor escala 40086)
  • 40092-40093: Energía Total Generada (32-bit Unsigned, Factor escala 40094)
  • 40196-40197: Tensión DC String 1 (16-bit, Factor escala 40198)
  • 40283: Estado Operacional (16-bit: 1=Off, 2=Sleeping, 3=Starting, 4=MPPT, 5=Throttled)

Implementación Python para Lectura:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registros 40084-40085)
result = client.read_holding_registers(40084, 2, unit=1)
if not result.isError():
# Convertir registros a float32
raw_power = (result.registers[0] << 16) | result.registers[1]
scale_factor = client.read_holding_registers(40086, 1, unit=1).registers[0]
actual_power = raw_power * (10 ** scale_factor)
print(f'Potencia AC: {actual_power} W')

# Leer estado operacional
status = client.read_holding_registers(40283, 1, unit=1).registers[0]
estados = {1:'Apagado', 2:'Standby', 3:'Iniciando', 4:'MPPT', 5:'Limitado'}
print(f'Estado: {estados.get(status, "Desconocido")}')

client.close()

Validar función code 0x03 (Read Holding Registers) habilitada en configuración Fronius Solar.web. Para instalaciones multi-string, iterar registros 40196+ según cantidad de strings configurados.
