Comunicación Modbus TCP con Inversores Fronius Symo: Registros y Implementación

Guía práctica para implementar comunicación Modbus TCP con inversores Fronius Symo, incluyendo registros reales y código Python.

Los inversores Fronius Symo implementan comunicación Modbus TCP en el puerto 502, utilizando el protocolo SunSpec Alliance para estandarización de registros. La configuración requiere habilitar la interfaz Modbus en el menú de comunicación del inversor.

Configuración de Registros Principales:

  • Dirección Modbus: 1 (configurable 1-247)
  • Registro base SunSpec: 40001
  • Identificador SunSpec: 40003-40004 ('SunS')
  • Potencia AC instantánea: 40084-40085 (INT32, W)
  • Voltaje DC String 1: 40258-40259 (UINT16, 0.1V)
  • Corriente DC String 1: 40260-40261 (UINT16, 0.1A)
  • Temperatura interna: 40109 (INT16, 1°C)
  • Estado operacional: 40108 (UINT16)

Implementación en Python usando pymodbus:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100')
connection = client.connect()

# Leer potencia AC (registros 40084-40085)
result = client.read_holding_registers(83, 2, unit=1)
potencia_ac = (result.registers[0] << 16) | result.registers[1]

# Leer voltaje DC String 1
result = client.read_holding_registers(257, 1, unit=1)
voltaje_dc = result.registers[0] * 0.1

print(f'Potencia AC: {potencia_ac}W')
print(f'Voltaje DC: {voltaje_dc}V')

client.close()

Para implementaciones en Colombia, considerar la configuración de red local y firewall. Los inversores Fronius Symo requieren firmware mínimo 3.8.1 para soporte completo Modbus TCP. La lectura de registros debe realizarse con función code 03 (Read Holding Registers), respetando los intervalos de polling recomendados de máximo 1 segundo para evitar sobrecarga del procesador interno del inversor.

Implementación SNMP v3 para UPS Eaton 9PX con Zabbix 6.x en Colombia

Configuración completa de monitoreo SNMP v3 seguro para UPS Eaton 9PX usando Zabbix 6.x con OIDs específicos y plantillas

El monitoreo SNMP v3 de UPS Eaton 9PX en infraestructuras críticas requiere configuración precisa de autenticación y cifrado. Esta implementación utiliza Zabbix 6.x para supervisión en tiempo real.

Configuración SNMP v3 en Eaton 9PX:

  • Usuario SNMPv3: eaton_monitor
  • Autenticación: SHA-256
  • Privacidad: AES-128
  • Contexto: "" (vacío)

Los OIDs críticos para monitoreo incluyen:

xupsInputVoltage: 1.3.6.1.4.1.534.1.3.1.0
xupsOutputVoltage: 1.3.6.1.4.1.534.1.4.1.0
xupsBatteryCapacity: 1.3.6.1.4.1.534.1.2.1.0
xupsOutputLoad: 1.3.6.1.4.1.534.1.4.3.0
xupsAlarms: 1.3.6.1.4.1.534.1.7.1.0

Script Python para validación:

from pysnmp.hlapi import *

def monitor_eaton_ups(target_ip):
    for (errorIndication, errorStatus, errorIndex, varBinds) in nextCmd(
        SnmpEngine(),
        UsmUserData('eaton_monitor', 'auth_pass', 'priv_pass',
                     authProtocol=usmHMACSHAAuthProtocol,
                     privProtocol=usmAesCfb128Protocol),
        UdpTransportTarget((target_ip, 161)),
        ContextData(),
        ObjectType(ObjectIdentity('1.3.6.1.4.1.534.1.2.1.0')),
        lexicographicMode=False):
        print(f'Batería: {varBinds[0][1]}%')

En Zabbix 6.x, configurar host con interfaz SNMP usando Security Level: authPriv, Context name vacío y timeout de 10 segundos para redes colombianas. Las plantillas Eaton oficiales requieren personalización para OIDs específicos del 9PX.

Esta configuración garantiza monitoreo seguro y confiable de infraestructura eléctrica crítica.

Comunicación Modbus TCP con Inversores Fronius Symo: Registros y Configuración

Configuración práctica de Modbus TCP en Fronius Symo con registros reales, códigos de función y Python para monitoreo

Los inversores Fronius Symo implementan comunicación Modbus TCP estándar para monitoreo remoto, esencial en instalaciones solares comerciales en Colombia. La configuración requiere habilitar Modbus en el menú Communication → Modbus del inversor.

Configuración de red:

  • Puerto TCP: 502 (estándar Modbus)
  • Unit ID: 1 (configurable)
  • IP estática recomendada para estabilidad

Los registros principales utilizan Function Code 03 (Read Holding Registers):

Registros críticos Fronius Symo:

  • 40084: Potencia AC actual (W, Int32)
  • 40092: Energía total generada (Wh, UInt64)
  • 40108: Voltaje DC String 1 (V, Int16, Factor 0.1)
  • 40110: Corriente DC String 1 (A, Int16, Factor 0.1)
  • 40118: Temperatura inversor (°C, Int16, Factor 0.1)
  • 40151: Estado operacional (0=Arranque, 1=Funcionando, 2=Apagado)

Implementación Python:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100')
connection = client.connect()

# Leer potencia AC actual (registro 40084)
result = client.read_holding_registers(84, 2, unit=1)
if not result.isError():
    power = (result.registers[1] << 16) | result.registers[0]
    print(f'Potencia actual: {power} W')

client.close()

Para instalaciones con múltiples inversores, configurar Unit IDs únicos (1-247) y polling secuencial. Considerar timeout de 5 segundos mínimo para redes WiFi inestables, común en zonas rurales colombianas.

Los registros principales utilizan función code 0x04 (Read Input Registers):

40084: Potencia AC instantánea (W)
40092: Voltaje DC String 1 (V)

40098: Temperatura inversor (°C)

Implementación en Python usando pymodbus:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registro 40084, dirección 83)
result = client.read_input_registers(83, 2, unit=1)
if result.isError():
    print('Error de comunicación')
else:
    potencia = (result.registers[0] << 16) | result.registers[1]
    print(f'Potencia AC: {potencia} W')

# Leer voltaje DC String 1
voltaje_dc = client.read_input_registers(91, 1, unit=1)
print(f'Voltaje DC: {voltaje_dc.registers[0]/100} V')

client.close()

La comunicación Modbus TCP con inversores Fronius Symo requiere configuración específica del protocolo SunSpec en puerto TCP 502. Los inversores utilizan Unit ID 1 por defecto y direcciones base iniciando en registro 40001.

Registros clave para monitoreo:

  • Registro 40084: Potencia AC actual (W) - INT16
  • Registro 40092: Corriente AC L1 (A) - UINT16, factor escala 0.1
  • Registro 40096: Tensión AC L1-N (V) - UINT16, factor escala 0.1
  • Registro 40108: Frecuencia (Hz) - UINT16, factor escala 0.01
  • Registro 40118: Energía total generada (Wh) - UINT32
  • Registro 40107: Estado operativo - UINT16

Para implementación en Python con pymodbus:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100')
result = client.read_holding_registers(40084, 1, unit=1)
potencia_ac = result.registers[0]
if potencia_ac > 32767:
    potencia_ac = potencia_ac - 65536
print(f'Potencia AC: {potencia_ac} W')

# Leer tensión con factor escala
tension_raw = client.read_holding_registers(40096, 1, unit=1)
tension_ac = tension_raw.registers[0] * 0.1
print(f'Tensión AC: {tension_ac} V')
