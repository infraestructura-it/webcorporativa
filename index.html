Comunicación Modbus TCP con Inversores Fronius Symo: Registros y Configuración

Configuración práctica de Modbus TCP en Fronius Symo con registros reales, códigos de función y Python para monitoreo

Los inversores Fronius Symo implementan comunicación Modbus TCP estándar para monitoreo remoto, esencial en instalaciones solares comerciales en Colombia. La configuración requiere habilitar Modbus en el menú Communication → Modbus del inversor.

Configuración de red:

  • Puerto TCP: 502 (estándar Modbus)
  • Unit ID: 1 (configurable)
  • IP estática recomendada para estabilidad

Los registros principales utilizan Function Code 03 (Read Holding Registers):

Registros críticos Fronius Symo:

  • 40084: Potencia AC actual (W, Int32)
  • 40092: Energía total generada (Wh, UInt64)
  • 40108: Voltaje DC String 1 (V, Int16, Factor 0.1)
  • 40110: Corriente DC String 1 (A, Int16, Factor 0.1)
  • 40118: Temperatura inversor (°C, Int16, Factor 0.1)
  • 40151: Estado operacional (0=Arranque, 1=Funcionando, 2=Apagado)

Implementación Python:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100')
connection = client.connect()

# Leer potencia AC actual (registro 40084)
result = client.read_holding_registers(84, 2, unit=1)
if not result.isError():
    power = (result.registers[1] << 16) | result.registers[0]
    print(f'Potencia actual: {power} W')

client.close()

Para instalaciones con múltiples inversores, configurar Unit IDs únicos (1-247) y polling secuencial. Considerar timeout de 5 segundos mínimo para redes WiFi inestables, común en zonas rurales colombianas.

Comunicación Modbus TCP con Inversores Fronius Symo: Registros y Configuración

Aprenderá a implementar comunicación Modbus TCP con inversores Fronius Symo, incluyendo registros clave y código Python.

Los inversores Fronius Symo implementan Modbus TCP de forma nativa, facilitando la integración en sistemas SCADA y de monitoreo para proyectos solares en Colombia. La configuración requiere habilitar el protocolo vía interfaz web del inversor.

Configuración inicial:

  • Acceder a Settings → Communication → Modbus TCP
  • Enable: Yes, Port: 502 (estándar)
  • Unit ID: 1 (por defecto)

Los registros principales utilizan función code 0x04 (Read Input Registers):

40084: Potencia AC instantánea (W)
40092: Voltaje DC String 1 (V)
40093: Corriente DC String 1 (A)
40098: Temperatura inversor (°C)
40107: Estado operativo (enum)
40118: Energía total generada (Wh)

Implementación en Python usando pymodbus:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registro 40084, dirección 83)
result = client.read_input_registers(83, 2, unit=1)
if result.isError():
    print('Error de comunicación')
else:
    potencia = (result.registers[0] << 16) | result.registers[1]
    print(f'Potencia AC: {potencia} W')

# Leer voltaje DC String 1
voltaje_dc = client.read_input_registers(91, 1, unit=1)
print(f'Voltaje DC: {voltaje_dc.registers[0]/100} V')

client.close()

Consideraciones técnicas:

  • Algunos valores requieren factor de escala (/100 o /1000)
  • Timeout recomendado: 3 segundos
  • Polling máximo: cada 5 segundos para evitar sobrecarga

Esta implementación permite integrar inversores Fronius con sistemas de monitoreo existentes, optimizando la operación de plantas solares comerciales e industriales.

Comunicación Modbus TCP con Inversores Fronius Symo: Registros y Códigos

Aprenderá registros Modbus reales, direcciones y códigos de función para monitorear inversores Fronius Symo en proyectos solares

La comunicación Modbus TCP con inversores Fronius Symo requiere configuración específica del protocolo SunSpec en puerto TCP 502. Los inversores utilizan Unit ID 1 por defecto y direcciones base iniciando en registro 40001.

Registros clave para monitoreo:

  • Registro 40084: Potencia AC actual (W) - INT16
  • Registro 40092: Corriente AC L1 (A) - UINT16, factor escala 0.1
  • Registro 40096: Tensión AC L1-N (V) - UINT16, factor escala 0.1
  • Registro 40108: Frecuencia (Hz) - UINT16, factor escala 0.01
  • Registro 40118: Energía total generada (Wh) - UINT32
  • Registro 40107: Estado operativo - UINT16

Para implementación en Python con pymodbus:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100')
result = client.read_holding_registers(40084, 1, unit=1)
potencia_ac = result.registers[0]
if potencia_ac > 32767:
    potencia_ac = potencia_ac - 65536
print(f'Potencia AC: {potencia_ac} W')

# Leer tensión con factor escala
tension_raw = client.read_holding_registers(40096, 1, unit=1)
tension_ac = tension_raw.registers[0] * 0.1
print(f'Tensión AC: {tension_ac} V')

Consideraciones técnicas: Los registros INT16 negativos requieren conversión desde UINT16. Configurar timeout mínimo 3 segundos para comunicación estable. En instalaciones colombianas, verificar configuración de red y firewall del inversor mediante interfaz web Fronius Solar.web.

Esta implementación permite monitoreo en tiempo real para sistemas SCADA y plataformas IoT, esencial en proyectos de generación distribuida conforme a resolución CREG 030 de 2018.

Configuración inicial:

  • Dirección IP estática del inversor
  • Puerto Modbus TCP: 502
  • Unit ID: 3 (por defecto)
  • Timeout: 10 segundos

Los registros principales para monitoreo incluyen:

  • 30775-30776: Potencia AC total (32-bit, W)
  • 30783-30784: Voltaje DC String 1 (32-bit, 0.01V)
  • 30977-30978: Corriente AC L1 (32-bit, mA)
  • 30513: Estado operacional (16-bit)
  • 30201: Temperatura interna (16-bit, 0.1°C)

Código Python para lectura:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100')
client.connect()

# Leer potencia AC (registros 30775-30776)
result = client.read_holding_registers(30775, 2, unit=3)
if result.isError():
    print('Error en comunicación')
else:
    power = (result.registers[0] << 16) + result.registers[1]
    print(f'Potencia AC: {power} W')

client.close()

Comunicación Modbus TCP con Inversores Fronius Symo: Implementación Práctica

Aprenderá registros Modbus específicos, códigos de función y configuración para monitoreo remoto de inversores solares

Los inversores Fronius Symo implementan protocolo Modbus TCP en puerto 502, facilitando la integración con sistemas SCADA y plataformas de monitoreo en instalaciones fotovoltaicas colombianas.

Configuración de Comunicación

Habilitar Modbus TCP desde la interfaz web del inversor: Communication → Modbus → TCP enabled. El Slave ID por defecto es 1, modificable según topología de red.

Registros Modbus Críticos

  • 40092 (FC03): Potencia AC instantánea [W] - INT32
  • 40098 (FC03): Energía total generada [Wh] - UINT64
  • 40106 (FC03): Voltaje DC String 1 [V] - UINT16, factor 0.1
  • 40108 (FC03): Corriente DC String 1 [A] - UINT16, factor 0.1
  • 40118 (FC03): Temperatura inversor [°C] - INT16, factor 0.1
  • 40139 (FC03): Estado operacional - UINT16

Implementación Python

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registro 40092, 2 registros INT32)
result = client.read_holding_registers(40092, 2, unit=1)
power_ac = (result.registers[0] << 16) + result.registers[1]

# Leer voltaje DC String 1
voltage_result = client.read_holding_registers(40106, 1, unit=1)
dc_voltage = voltage_result.registers[0] * 0.1

print(f"Potencia AC: {power_ac} W")
print(f"Voltaje DC: {dc_voltage} V")

client.close()

Consideraciones de Implementación

El polling excesivo puede afectar rendimiento del inversor. Recomendamos intervalos mínimos de 5 segundos. Para instalaciones con múltiples inversores, implementar connection pooling y manejo de timeouts robusto.

Los valores requieren aplicación de factores de escala específicos según documentación Fronius Solar API.

Configuración inicial:

  • Habilitar Modbus TCP en Fronius Solar.web
  • Configurar dirección IP estática del inversor
  • Unit ID por defecto: 1

Los registros principales utilizan función code 03 (Read Holding Registers) con direcciones específicas:

Registros clave Fronius Symo:

  • 40083-40084: Potencia AC total (32-bit, Watts)
  • 40085-40086: Energía total generada (32-bit, Wh)
  • 40087: Voltaje DC String 1 (16-bit, 0.1V)
  • 40089: Corriente DC String 1 (16-bit, 0.01A)
  • 40103: Voltaje AC L1-N (16-bit, 0.01V)
  • 40149: Estado del inversor (16-bit)

Implementación Python con pymodbus:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registros 40083-40084)
result = client.read_holding_registers(40083, 2, unit=1)
if result.isError():
print('Error de comunicación')
else:
# Combinar registros 32-bit
power_raw = (result.registers[0] << 16) + result.registers[1]
power_watts = power_raw if power_raw < 0x80000000 else power_raw - 0x100000000
print(f'Potencia AC: {power_watts} W')

client.close()

Comunicación Modbus TCP con Inversores Fronius Symo: Registros y Implementación

Aprenderás registros Modbus reales, códigos de función y implementación Python para monitoreo de inversores Fronius Symo

Los inversores Fronius Symo utilizan protocolo Modbus TCP en puerto 502 para comunicación industrial. La configuración requiere habilitar Modbus en el inversor vía interfaz web (Comunicación → Modbus → TCP activado).

Registros principales para lectura:

  • Potencia AC actual: Registro 40083-40084 (32-bit Float, Factor escala 0.01W)
  • Voltage AC L1: Registro 40085 (16-bit, Factor 0.1V)
  • Corriente AC L1: Registro 40086 (16-bit, Factor 0.01A)
  • Energía total: Registro 40093-40094 (32-bit, Factor 1Wh)
  • Temperatura inversor: Registro 40103 (16-bit, Factor 0.1°C)
  • Estado operativo: Registro 40107 (valores: 2=Funcionando, 3=Standby, 7=Error)

El código de función 03 (Read Holding Registers) es estándar para estos registros. Dirección Modbus por defecto: 1.

Implementación Python usando pymodbus:

from pymodbus.client.sync import ModbusTcpClient

client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# Leer potencia AC (registros 40083-40084)
result = client.read_holding_registers(40082, 2, unit=1)
if result.isError():
print("Error lectura Modbus")
else:
# Combinar registros para valor 32-bit
power_raw = (result.registers[0] << 16) | result.registers[1]
power_w = power_raw * 0.01
print(f"Potencia AC: {power_w} W")

client.close()

Para instalaciones colombianas, considerar configuración de red estática en el inversor y firewall apropiado. La latencia típica es <50ms en redes LAN estables.

Troubleshooting común: Verificar que el firmware Fronius sea ≥4.7.1 para soporte Modbus completo y que no excedan 10 conexiones TCP simultáneas por limitación del inversor.

Modbus TCP con Fronius Symo: leer generación solar desde Node.js

Registros SunSpec exactos del Fronius Symo para monitoreo en tiempo real desde cualquier plataforma.

El inversor Fronius Symo implementa el protocolo SunSpec Modbus TCP en el puerto 502, compatible con cualquier cliente Modbus. El mapa de registros sigue el estándar SunSpec Alliance, con el bloque de identificación en la dirección 40001.

Registros clave para monitoreo solar (dirección base 40070 en Fronius Symo):

  • 40083 — Potencia CA total (int16, W) — generación instantánea
  • 40085 — Frecuencia CA (uint16, 0.01 Hz)
  • 40094 — Energía total producida (uint32, Wh acumulado)
  • 40107 — Temperatura del inversor (int16, 0.1 °C)
  • 40101 — Estado operativo (uint16): 4=MPPT activo, 5=regulando

Ejemplo con Node.js usando la librería modbus-serial:

const ModbusRTU = require('modbus-serial');
const client = new ModbusRTU();
await client.connectTCP('192.168.1.100', { port: 502 });
client.setID(1);
const data = await client.readHoldingRegisters(40083, 2);
const watts = data.data[0]; // potencia actual en W
console.log('Generación:', watts, 'W');

El factor de escala para potencia está en el registro 40084 (SF, int16). El valor real es registro × 10^SF. En la mayoría de instalaciones Fronius el SF es -1, por lo que el valor raw 1500 = 150.0 W.

Esta misma estructura funciona para SMA Sunny Boy y GoodWe con ajuste de dirección base según su manual SunSpec.
